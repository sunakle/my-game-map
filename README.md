# Мастерская карт

Отдельный браузерный редактор 3D-карт для планирования будущей игры. Карты состоят из объектов, групп, импортированных PNG и привязанных заметок. Код в этом репозитории публичный; пользовательские карты автоматически сюда не отправляются.

## Запуск

Нужны Node.js и npm. В папке проекта:

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5174`. Для проверки сборки: `npm run build`.

## Как работать

1. Нажмите «Создать карту». Пустая карта сохраняется в IndexedDB этого браузера.
2. На вкладке «Декор» выберите объект и щёлкните по земле. Вкладка «Сцена» показывает дерево объектов.
3. Выберите объект. На холсте перетаскивайте его; кнопки «Повернуть» и «Размер» меняют действие перетаскивания. Справа доступны точные координаты, размеры, поворот, цвет и игровые пометки.
4. Shift + щелчок выделяет несколько объектов. «Группа» создаёт группу, в том числе из уже созданных групп. Ctrl+Z и Ctrl+Y отменяют и повторяют действия. Ctrl+C и Ctrl+V копируют и вставляют объекты.
5. «Прикрепить заметку» связывает текст с выбранным объектом. Заметки карты создаются из вкладки «Заметки» или панели свойств без выбранного объекта.
6. «Файлы» → «Скачать архив карты» создаёт переносимый `.mgmap.zip`. Его можно открыть кнопкой «Открыть архив карты» на другом адресе или устройстве.

Готовый пример для проверки импорта: [`examples/forest-path.mgmap.zip`](examples/forest-path.mgmap.zip). Он содержит только временные декорации из встроенной библиотеки.

## Формат архива 1

`project.json` содержит единицу измерения (метр), стабильные UUID объектов и заметок, иерархию, мировые координаты в осях X/Y/Z, повороты в радианах, размеры, цвета, ссылки на ресурсы и игровые пометки. `assets/<UUID>.png` содержит рисунки пользователя. `overview.md` даёт краткий обзор сцены. `preview.png` — снимок вида при экспорте. Импорт полностью проверяет JSON и PNG до записи нового проекта. Импорт создаёт новую копию проекта с новым ID, сохраняя все ID объектов и связи заметок.

Формат готов для последующего преобразования в Godot 4.7.2. Игровые пометки являются данными проекта: они пока не создают коллизии, переходы и логику автоматически. Готовые декорации являются временными оригинальными геометрическими заготовками. Импорт 3D-моделей и редактирование произвольного рельефа запланированы на следующий этап; сейчас высота и форма площадок задаются свойствами объектов.

## Хранение и ограничения

Все изменения сохраняются локально после короткой паузы. Сайт в другом браузере или на другом адресе использует своё хранилище; переносите карты ZIP-архивом. Для PNG установлен предел 8 МиБ и 8192×8192, для архива — 30 МиБ, для карты — 2000 объектов. Публикация сайта не синхронизирует личные карты с GitHub.
