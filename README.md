# Мастерская карт и фигур

Редактор уровней с плоскими декорациями в трёхмерной сцене. При первом запуске открывается карта с кубом. Кнопка «Карты» открывает список документов. При повторном запуске восстанавливается последняя карта.

## Начало работы

1. Нажмите **Shift+A** и выберите куб, сферу, цилиндр или конус. Декорации и импорт PNG доступны на вкладке «Декор». Для размещения декорации щёлкните по сетке.
2. Для вращения вида удерживайте среднюю кнопку мыши. Shift со средней кнопкой сдвигает вид. Колесо меняет масштаб. Кнопки X, Y, Z в углу и цифровая клавиатура переключают виды.
3. Выберите фигуру. **G**, **R**, **S** начинают перенос, поворот и масштабирование. Например, **G → Z → 2 → Enter** поднимает её на два метра. **Esc** отменяет операцию. Несколько объектов выбираются с Shift.
4. В «Геометрии» задайте скругление и число сегментов. Для точного среза раскройте «Срез по плоскости», выберите ось и смещение, затем нажмите «Применить срез». В режиме граней (**Tab**) клавиша **K** позволяет провести линию двумя щелчками и отсечь одну сторону. **F** меняет отбрасываемую сторону перед вторым щелчком. **Ctrl+B** меняет скругление всех выраженных рёбер фигуры. Выберите грань и нажмите **E**, чтобы вытянуть её наружу. Числа вводятся с точкой. Ctrl+Z отменяет действие.
5. Во вкладке «Сцена» можно собрать выбранные объекты в группу. В свойствах доступны цвет, положение, поворот, размер и привязанные заметки. Полный список сочетаний редактора открывается кнопкой «Клавиши».
6. «Экспорт карты» создаёт переносимый архив. «Файлы» → «Открыть архив карты» загружает отдельную редактируемую копию. Индикатор в заголовке сообщает о завершении локального сохранения.

## Windows

Запустите **MapStudio-0.2.0-Windows-x64.exe**. Программа работает офлайн и сохраняет карты в профиле приложения. У сайта и EXE разные хранилища. Для переноса используйте архив карты.

В EXE у выбранной фигуры есть кнопка **«Открыть в Blender»**. Она открывает отдельный сеанс установленного Blender с геометрией фигуры. Используйте обычные инструменты Blender для вершин, рёбер и граней, затем нажмите **«Вернуть в карту»** в заголовке 3D-вида. Закрытие сеанса без этой команды оставляет исходную фигуру в карте. После возврата доступны преобразования, цвет и повторный переход в Blender. В карту возвращается полигональная сетка со всеми применёнными модификаторами. UV, материалы Blender, анимация и стек модификаторов в этот обмен не входят.

## Сборка из исходников

Используйте Node.js 22.18 или новее и npm. Выполните `npm ci` и `npm run dev`. Локальный сайт доступен по адресу `http://127.0.0.1:5174`. Проверки запускаются командой `npm test`, сборка сайта — `npm run build`. Для упаковки Windows x64 выполните `npm run package:win` в Windows. Результат появится в каталоге `release/`.

## Перенос в Godot

В ZIP находятся `project.json`, `overview.md`, исходные PNG из `assets/` и снимок вида `preview.png`. JSON версии 1 содержит стабильные ID объектов и заметок, группы, координаты, повороты, масштаб, цвет и игровые пометки. Связи заметок сохраняются по ID. Можно открыть [пример лесной карты](examples/forest-path.mgmap.zip).

В документе метр соответствует единице Godot, Y направлена вверх, повороты задаются в радианах в порядке XYZ Three.js. В интерфейсе показаны оси Blender. Точке Blender (x, y, z) соответствует (x, z, −y) в документе. Координаты объектов мировые, иерархия обозначает группы. При создании вложенных Node3D необходимо перевести мировые преобразования в локальные.

Для объектов `solid` сохранены тип примитива, скругление, число сегментов и плоскости среза в локальных координатах (`normal · point <= offset`). Вытянутая выпуклая форма может содержать `hull`. После обмена с Blender в `mesh` хранятся вершины, полигоны и треугольники для построения ArrayMesh. При переносе учитывайте лицевую сторону и порядок вершин движка. Автосоздание игровой логики относится к работе над уровнем в Godot.

## Пределы документа

До 2 000 объектов. Один PNG — до 8 МиБ и 8192×8192. Архив — до 30 МиБ, описание — до 20 МиБ. Проверка предшествует сохранению импортированной карты. Браузерные операции с гранями рассчитаны на выпуклые примитивы. Сложные и вогнутые сетки можно создавать и редактировать через установленный Blender в Windows-версии.
